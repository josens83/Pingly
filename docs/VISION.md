# Pingly 프로젝트 비전

## 한 줄 정의
비즈니스를 위한 SMS 및 메신저 마케팅 플랫폼

## 대상 사용자
마케팅 캠페인을 효율적으로 관리하고 싶은 중소기업 마케터

## 해결하는 문제
- 여러 채널(SMS, 메신저)을 통합 관리하기 어려움
- 캠페인 성과 분석이 분산되어 있음
- 대량 메시지 발송의 복잡성

## 핵심 가치 (3개)
1. **통합성** - SMS와 메신저를 하나의 플랫폼에서 관리
2. **효율성** - 간편한 캠페인 생성 및 자동화
3. **분석력** - 실시간 성과 분석 및 인사이트 제공

## 핵심 기능 (MVP)
- [x] 사용자 인증 (로그인/회원가입)
- [x] 대시보드
- [ ] 연락처 관리
- [ ] 캠페인 생성 및 관리
- [ ] 메시지 템플릿
- [ ] 기본 분석 리포트

## 🚫 목표 NOT (명시적으로 하지 않을 것)
- CRM 기능 (별도 CRM과 연동)
- 이메일 마케팅 (SMS/메신저에 집중)
- 소셜 미디어 관리
- 고객 서비스/챗봇 기능
- 모바일 앱 (웹 반응형으로 대체)

## 성공 지표
- 캠페인 생성 5분 이내 완료
- 대시보드 로딩 2초 이내
- 메시지 발송 성공률 99% 이상
- 분석 리포트 실시간 업데이트
